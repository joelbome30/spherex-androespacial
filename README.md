# SPHEREx · Proyecto escolar

Página de Gabriela Meza, grado 8D, sobre la misión SPHEREx.

Para ver la página sin servidor, abre `index.html` con doble clic desde el explorador de archivos. Ese archivo contiene sus estilos, JavaScript, fuente e imágenes, así que también funciona en Zen sin cargar archivos adicionales.

En Windows, abre `abrir-pagina.bat` con doble clic para iniciar un servidor local y abrir la versión editable en el navegador. Usa PowerShell, incluido en Windows 10 y 11; no requiere VS Code ni instalaciones. Cierra la ventana del servidor o pulsa Ctrl+C para detenerlo.

`pagina-base.html`, `style.css` y `script.js` son los archivos editables. `index.html` es la versión autónoma. Las noticias son una selección fija y los filtros funcionan con JavaScript.

Imágenes: NASA/JPL-Caltech, [mapa de SPHEREx](https://svs.gsfc.nasa.gov/31376/) , [nube de Cygnus X](https://science.nasa.gov/photojournal/nasas-spherex-mission-maps-water-ice-throughout-cygnus-x/) y [nube de polvo](https://science.nasa.gov/photojournal/spherexs-dust-cloud-reveal/).
